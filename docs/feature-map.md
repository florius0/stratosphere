## Initial-scope exclusions

- Automatic resource-pressure unloading (D-04).
- Multi-workspace ownership of one ordinary window, multiple tiled groups per leaf (D-05, D-08).
- Third-party integration plugins/process protocol (D-13); third-party IPC/CLI/file integration remains supported.
- User/runtime backend selection and automatic native-Space-switch handling with a virtual backend (D-02).
- Competing-manager detection or blocking (D-24).
- Adaptive runtime handling of private-API incompatibility (D-25).
- Fine-grained resource locking (D-18), until measurement justifies it.

## Not yet guaranteed

Native Spaces viability, native full-screen preservation/navigation with the virtual backend, private notification-action replay, green-button replacement, and exact gesture mechanisms are unresolved feasibility, not omitted research. VS Code fidelity is deliberately revisitable. Generic independent window cloning is not assumed. See [decision map](decision-map.md#open-questions-and-proposed-mechanisms).
